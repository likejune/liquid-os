# Ядро Liquid

- `config/liquid.config` — фрагмент конфигурации поверх конфига Fedora.
- `patches/*.patch` — патчи Liquid, применяются по алфавиту.

Сборка своего пакета ядра: исходный пакет kernel из Fedora + эти патчи → свой RPM, который mkosi берёт из локального репозитория (`mkosi.packages/`). Пока патчей нет, используется стоковое ядро.
