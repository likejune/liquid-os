# Secure Boot и подписи

## Ключи
| Ключ | Для чего | Где хранится |
|---|---|---|
| mkosi.key / mkosi.crt | подпись systemd-boot, UKI, корневого хеша dm-verity, модулей NVIDIA | секреты GitHub `MKOSI_KEY`, `MKOSI_CRT` |
| gnupg (ed25519) | подпись SHA256SUMS для systemd-sysupdate | офлайн + секрет для CI |

Создание: `scripts/secureboot-keys.sh keys`.

## Загрузка на компьютерах с Secure Boot
На обычных ПК в прошивке записаны только ключи Microsoft, поэтому наш ключ нужно добавить одним из способов:
1. **Автозапись ключей systemd-boot** — компьютер в режиме Setup Mode, при первой загрузке ключ Liquid OS записывается сам. Подходит для тестов и опытных пользователей.
2. **shim + MOK** — shim, подписанный Microsoft, грузится везде; при установке пользователь один раз подтверждает ключ Liquid OS. Собственный shim, подписанный Microsoft, требует прохождения shim-review — долгий процесс, планировать заранее.

Решение для 1.0: вариант 1 в бете, подача на shim-review параллельно; если не успеет к релизу — инструкция в установщике по включению Setup Mode.
