# Liquid OS 1.0 — черновик release notes

**Новая система. Новое ощущение.**

## Что внутри
- Интерфейс Liquid Glass: стеклянные окна и панели с размытием и радужной кромкой, светлая и тёмная темы, 6 акцентных цветов.
- Верхняя панель, плавающий док, меню приложений с поиском, пункт управления, уведомления.
- Приложения: Finder, Заметки, Настройки, Центр обновлений, О системе.
- Тысячи приложений из Flathub.
- Атомарные обновления: система обновляется целиком и сама откатывается при ошибке.
- Драйвер NVIDIA из коробки, шифрование данных, Secure Boot.

## Системные требования (предварительно)
64-битный процессор x86, UEFI, 4 ГБ ОЗУ, 32 ГБ диска, видеокарта с Vulkan или OpenGL 3.3.

## Известные ограничения
- Нет поддержки ARM и планшетов.
- На компьютерах с Secure Boot может понадобиться одноразово добавить ключ Liquid OS.
