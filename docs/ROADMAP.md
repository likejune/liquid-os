# Roadmap

Рабочий план ведётся на доске monday «Liquid OS: план релиза».

1. Продукт (PRD, решения, недостающие экраны) — готово
2. Основа системы (mkosi, атомарность, ядро) — в работе
3. Liquid UI (токены, стили компонентов, геометрия) — на ревью; адаптер к iced далее
4. Liquid Compositor (раскладка оболочки, декорации, шейдеры стекла) — в работе; бэкенд Smithay далее
5. Liquid Shell
6. Приложения и порталы
7. Установщик и первая настройка
8. Обновления и безопасность (ключи, публикация обновлений, план тестов) — на ревью
9. Релиз (чек-лист, release notes, workflow release) — подготовлено
