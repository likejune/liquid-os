# Драйвер NVIDIA в атомарном образе

Проблема: akmods собирает модули ядра на компьютере пользователя, а /usr у нас только для чтения.

Решение:
1. При сборке образа собирать модули NVIDIA (open kernel modules) под точную версию ядра образа.
2. Подписывать их ключом Liquid OS (тот же, что для Secure Boot).
3. Класть модули и библиотеки в /usr, как часть образа. Обновление драйвера приходит вместе с обновлением системы.
4. Выпускать два варианта образа или один с обоими драйверами: Mesa (nouveau/NVK) и NVIDIA, выбор по устройству.

Источник пакетов: RPM Fusion nonfree. Включение: `LIQUID_NVIDIA=1 mkosi -f build` после добавления файла репозитория в `mkosi.sandbox/etc/yum.repos.d/`.

Статус: спроектировано, не проверено сборкой.
