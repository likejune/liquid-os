# План тестирования на железе

## Матрица устройств (минимум для 1.0)
| # | Класс | Видео | Пример |
|---|---|---|---|
| 1 | Виртуальная машина | virtio-gpu | QEMU/KVM, VirtualBox 7 |
| 2 | Ноутбук Intel | Intel Xe / Arc | любой ноутбук 2022+ |
| 3 | Ноутбук AMD | Radeon 7xxM | Ryzen 7040/8040 |
| 4 | ПК NVIDIA | GeForce RTX 30/40 | закрытый драйвер |
| 5 | Ноутбук гибрид | Intel + NVIDIA | переключение видеокарт |
| 6 | Слабый ПК | встроенная, 4 ГБ ОЗУ | проверка минимальных требований |

## Проверки на каждом устройстве
- [ ] Загрузка с USB, экран загрузки Liquid
- [ ] Установка по всем 8 экранам, первая настройка по 7 экранам
- [ ] Стекло: размытие под панелью, доком, окнами; 60 кадров/с при перетаскивании окна
- [ ] Несколько мониторов, HiDPI 150% и 200%
- [ ] Wi-Fi (WPA2, WPA3), Bluetooth (наушники, мышь)
- [ ] Звук: динамики, наушники, микрофон, HDMI
- [ ] Яркость и громкость из пункта управления и клавиш
- [ ] Сон и пробуждение, работа от батареи
- [ ] Flatpak: браузер, LibreOffice, телеграм, игра через Steam
- [ ] Обновление A→B и автооткат (специально сломанная версия должна откатиться после 3 попыток)
- [ ] Secure Boot включён
- [ ] «О системе» показывает настоящие данные
