# Звуки Liquid OS

## desktop-login.oga — приветствие при входе
- Длительность 3,2 с, 48 кГц, стерео, пик −1 dBFS.
- Идея: «капля» (быстрый взлёт тона) → стеклянное арпеджио Ре мажор add9 (D5, F#5, A5, E6) с панорамой слева направо → тёплая подложка и мягкий хвост реверберации. Созвучно стилю Liquid Glass: лёгкий, воздушный, «стеклянный».
- Синтезирован с нуля (без сэмплов), принадлежит Liquid OS.
- Имя по стандарту freedesktop: `desktop-login`, тема звуков `liquid`.
- Играется службой `liquid-login-sound.service` после старта графического сеанса, громкость 60%.
- Отключение: файл `~/.config/liquid/login-sound` со словом `off` (переключатель «Звук при входе» в Настройки → Звук).
